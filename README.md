🚀 Getting Started

Clone project
git clone https://github.com/Anastasiia-git/MovieFinder.git
cd movie-explorer
Install dependencies
npm install
Run locally
npm run dev

🔑 Environment Variables

Create .env file in root:
VITE_API_KEY=your_api_key_here
⚠️ Never commit API keys.
